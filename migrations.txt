Uma requisição http é composta por:

    1. Linha de requisição: método + utl + versão do protocolo

    2. Headers: pares de chave:valor enviados pelo cliente para dar contexto ao servidor:
        accept: tipos de mídias aceitos(application/json)
        host
        authorization: bearer token
        content-type: corpo enviado, app/json, www-forms, buffer

    3. Body opcional

Response: Linha de status, response header, corpo da resposta
